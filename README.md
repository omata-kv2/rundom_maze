# YAJU ESCAPE v20 (音声完全再生・Safari/Chrome両対応版)

## v20 での修正・追加内容
1. **Safari / Chrome の「音付き動画自動再生ブロック」を完全回避**:
   - iOS (Safari) や Chrome では、ユーザーの操作（タップ/クリック）を経由しない音声付き動画の自動再生がブラウザ仕様で強力にブロックされ、真っ黒になるかフリーズします。
   - プレイヤーが「ゲーム開始」ボタンを押した瞬間のユーザー操作コンテキストの中でメディア要素のオーディオ権限をアンロック（解除）するように設計。
   - これにより、動画プレイヤーが捕獲時に音付き（`muted = false`）でスムーズかつフリーズせずにフル再生されるようになりました。
