# YAJU ESCAPE v23.8 (アップデート版)

## 主な実装・変更内容
1. **追跡者の段差上スポーン保証**:
   - スポーン位置のセルに段差・トラップがある場合、必ずその段差の上面に生成されるように高さを補正しました。
2. **ボスステージ共通マップ仕様（10×10セル）**:
   - 外枠を覆う壁以外の内部壁は生成せず、床・天井・赤色ライト・段差・トラップ・ロケットおよび各種当たり判定を配置しました。
3. **World Enemy戦の全面改修**:
   - **配置**: 部屋の中央 `(0, 0)` に生成（中央から半径2セル以内には段差を生成しない）。プレイヤーは部屋の角 `(1, 1)` に生成。
   - **見た目・当たり判定**: 天井までの高さ（`4.53m`）の立方体で全6面に `./assets/chasers/izan.png` を貼付。立方体と同じサイズの当たり判定を実装。
   - **攻撃・行動**: 中央から移動せず、スタートから **3秒ごと** に直線飛行する **青色弾頭（速度12・被弾時4ダメージ）** を発射。
   - **家臣産出**: スタート時点および **10秒毎（CD）** にノーマル追跡者（caught無効・接触時4ダメージ・CD2秒）を2体中央にスポーンさせ、同時に **240rpmで2秒間** 時計回りにY軸回転を行います。
4. **ボスHPバーUI（HP 100）**:
   - 「獣王」「World Enemy」ともにHP 100を設定。ボスステージ中はコンパス表示を透明化し、右上のコンパスがあった場所の最前面にボスHPバーを表示します。
5. **ボスステージ挑戦制限**:
   - ノーマルステージの1〜4階クリア時はボスステージ選択を非表示とし、**5階（最大階数）クリア時のみ** 出現するように制限しました（スタート前設定の「最初からボスに挑戦する」は免除）。
6. **Clear Stage（ホワイトアウト演出）**:
   - ボスHPが0になるとClear Stageへ移行し、3秒かけて最も透明な白から真っ白な霧へと変化させつつ全構造物・生成物を削除し、完了後にクリア画面を表示します。
7. **Death Stageの視点操作有効化**:
   - Death Stage中もタッチドラッグ（`look-pad`）およびマウス移動による視点操作を有効に維持しました。
