# YAJU ESCAPE v23.6 (アップデート版)

## 修正・実装内容
1. **スタート前ルール設定に「最初からボスに挑戦する (OFF/ON)」スライドボタンを追加**:
   - 初期状態は **OFF**。
   - **ON** に切り替えると、即座に無関係な **「各コンパスの使用」が自動的に OFF** になります。
   - 同時に「この設定でゲーム開始」ボタンが操作無効化（`disabled`）・最背面化（`z-index: -1`）・透明化（`opacity: 0`）され、その上に **「ボス: world enemyに挑戦」「ボス:獣王に挑戦」** の2つのボタンが縦に並んで操作可能状態で表示されます。
2. **YAJUコンパスの距離に応じた縁色変化の復活**:
   - 通常階層ステージにおいて、最も近い追跡者との距離に応じてYAJUコンパスの円周（縁）の色が動的に **緑（安全）→ 黄（警戒）→ 赤（接近・危険）** へと変化する機能を復活・実装しました。
