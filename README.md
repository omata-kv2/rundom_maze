# YAJU ESCAPE v17 (安定・描画精度・UI最適化版)

## v17 での修正・追加内容
1. **追跡者の壁貫通・めり込み修復**:
   - 敵の物理衝突半径（`enemyRadius: 0.5`）を考慮した移動衝突判定を実装し、壁すり抜けを完全防ぐ。

2. **チェイススピード調整**:
   - 追跡時のスピードを **`5.8`** に修正。

3. **yajuコンパスの完全作動修正**:
   - 敵との最短距離に応じたコンパスの枠色変化（緑/黄/赤）が作動しない問題を修正。

4. **ルール設定から「黒い霧」記述を削除**:
   - 雰囲気維持のため、黒い霧は常時有効化としルール選択パネルから項目を削除。

5. **青色発光マップ上ロケットのスポーン・取得修正**:
   - マップ上に青色の点光源（`0x00aaff`）をまとったロケットアイテムが1〜2個確実にスポーン。

6. **各階ごとのリセット処理**:
   - 各階層のスタート時にスタミナ（20満タン）および所持ロケット数を自動リセット。

7. **追跡者画像の白飛び（白点滅）防止**:
   - マテリアル設定に `depthWrite: false` を導入し、描画チラツキ・白飛びを抑止。

8. **全画面透過視点操作 & 右端ボタン最適化**:
   - 視点操作エリアを文字無しの完全全画面透過領域に変更。
   - アクションボタン（走る・挑発・発射）を右下にコンパクトに配置。
   - スティックの動く円の範囲を広く拡張（`maxRadius: 45`）。

9. **各種ブラウザ・iPad画面表示の安定化 & ロード画面追加**:
   - `viewport-fit=cover` & ダブルタップ/ジェスチャー拡大防止処理を実装。
   - ステージ生成時・次階層移行時にローディングインジケータ（ロード画面）を表示。
