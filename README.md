# MAZE ESCAPE - Backrooms Edition (v3)

## 概要
Three.jsを使用した、iPad対応の一人称視点ホラー迷路ゲームの第3次アップデート版です。

## 更新内容 (v3)
- **捕獲動画の再生不具合修正**: セキュリティ制限により動画や音声が停止しないよう、ゲーム開始時にメディアの自動再生ロックを解除する処理を追加。動画を最前面（z-index最適化）で再生するように修正しました。
- **フレームレート(FPS)の向上**: 壁の描画を `InstancedMesh` に変更したことで、描画コールが激減し動作が非常に滑らかになりました。
- **追跡者のスピード調整**:
  - 通常スピード：プレイヤーの歩きと同じ速度
  - 追跡時スピード：プレイヤーの走る速度より `0.2` 遅い速度
- **BGM(yarimasune.mp3)の追加**: 追跡者との距離に応じて音量が5段階(20%, 40%, 60%, 80%, 100%)でループ再生される機能を追加しました。
- **挑発ボタンの追加**: 
  - 画面右下の走るボタンの横（PCでは `E` キー）に配置。
  - 押すと `114514.mp3` を再生し、その位置（床）に赤い円のマーカーを付着。
  - 追跡者はどんな距離からでも、その地点へ向かって最短距離・追跡スピードで突進します（到着すると解除）。
- **テクスチャの自由変更**: 壁の模様を変える方法は以下に記載しています。

## ファイル構成と配置方法
以下の構成になるようにファイルを配置してください。
（ZIP内にはダミーファイルが含まれているため、本物のファイルで上書きしてください）

```
MAZE_ESCAPE_Backrooms/
├── index.html
├── style.css
├── game.js
├── README.md
└── assets/
    ├── chasers/
    │   └── inmu_king.png (本物の画像に差し替えてください)
    ├── sounds/
    │   ├── yarimasune.mp3 (ご自身で用意してください)
    │   └── 114514.mp3 (ご自身で用意してください)
    └── videos/
        └── inmuking.mp4  (本物の動画に差し替えてください)
```

## 壁のテクスチャ（模様）を自由に変更する方法
1. お好きな画像（例: `wall.jpg` や `wall.png`）を用意し、`assets/textures/` フォルダなどに保存します。
2. `game.js` ファイルをテキストエディタで開きます。
3. `buildWorld()` 関数の中に以下の行があります。
   ```javascript
   // loader.load('./assets/textures/wall.jpg', tex => { wallMat.map = tex; wallMat.needsUpdate = true; });
   ```
   この行の先頭にある `//` （コメントアウト）を消去し、ファイルパスを合わせたうえで保存してください。壁がその画像に張り替わります。

## 起動方法
ローカルサーバー（VSCodeのLive Server拡張機能など）を使用して `index.html` を開いてください。
