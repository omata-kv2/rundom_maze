# YAJU ESCAPE v16 (軽量化・操作改善・AI最適化版)

## v16 での修正・追加内容
1. **操作性の単純化・確実化（iPadタッチ不具合解消）**:
   - イベントキャプチャ（`setPointerCapture`）を厳格化し、スタート後にタッチスティックや視点操作、ボタン反応が効かなくなる問題を修正。

2. **ステージ全体の明るさ2倍化**:
   - 環境光（`HemisphereLight`）を **2.0**（従来比2倍）にし、ディレクショナルライトも明るく調整。

3. **ライト描画制限（プレイヤー向いてる方向 16.0先まで）**:
   - プレイヤーのカメラ前方（`dot > -0.2`）かつ 16.0m 以内にあるライトのみ計算・描画させることで処理負担を大幅削減。

4. **天井ライトの発光表現の改善**:
   - 電球メッシュ自体の発光（emissive）は抑えめにしつつ、周辺の壁・床を照らすPointLightの強度（12.0/15.0）を大幅に強化。

5. **iPad向け 30FPS 制限 & FPSカウンター追加**:
   - HUDにリアルタイムFPS表示を追加。
   - アニメーションループに30FPS上限を設けてiPadでの熱発生やコマ落ちを防止。

6. **ゴールの配置修正（15セル内側・対角）**:
   - ゴールをスタート地点（1,1）の真逆（13,13付近）の15セル内側に確実に配置。

7. **追跡者の動的AIアルゴリズム修正**:
   - **1体のみの場合**: スタートから10セルほど離れた場所でスポーンし、**最初から追跡モード(chase)**でプレイヤーを追撃。
   - **複数体の場合**: 1体が**ゴール（13,13付近）の周りを守るように巡回防衛**。
