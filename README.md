# YAJU ESCAPE v15 (5階層・ルールドラフト＆モジュール化版)

## 主な追加・変更機能 (v15)
1. **スタート前ルール設定パネル（スライドトグル機能）**:
   - **黒い霧の表示 ON / OFF**
   - **各コンパスの使用 (EXIT/野獣) ON / OFF**
   - **累進野獣数 (階層ごとに敵追加) ON / OFF**

2. **5階層ステージクリアシステム**:
   - 1階層ごとに **15×15セル** のコンパクト迷路を生成。
   - 階層をクリアするごとに次の階層へ進み、**5階クリアでゲーム全クリア**。
   - 「累進野獣数 ON」の場合、階層が上がるごとに追跡者の数が増加。

3. **天井の高さ変更**:
   - 天井の高さを従来（6.8）の **3分の2（4.53）** に調整。

4. **スタート時ランダムロケット要素**:
   - ステージ開始時、**10%の確率** で手元にロケット弾が1発支給される要素を追加。

5. **スタート時無敵時間**:
   - ステージ開始後 **3秒間** は敵の `Catch` 判定（ゲームオーバー判定）を無効化。

6. **ファイル構成のモジュール化（設計の分離）**:
   - `config.js`: 定数・設定データ
   - `collision.js`: 当たり判定・視界計算・セル変換ロジック
   - `worldBuilder.js`: 迷路生成およびThree.jsシーン構築ロジック
   - `main.js`: ゲームループ・UI・イベント処理
