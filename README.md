# YAJU ESCAPE v21 (A* Pathfinding / 段差 / トラップモンスター / 突進機能)

## v21 の新機能・改善点

1. **追跡者の A* Pathfinding アルゴリズム導入（壁引っかかり防止）**:
   - チェイス中・通常移動時にグリッドベースの最短経路をリアルタイム計算[cite: 19.1]。
   - 複雑な迷路の角や壁に引っかかることなく、プレイヤーへ向けて最短ルートで移動[cite: 19.1]。

2. **段差 (高低差) & 不動トラップモンスターの自動生成**:
   - 各階層に段差＋トラップを合計 15〜25 個ランダム生成（うち 33% の確率でトラップモンスター化）[cite: 19.1]。
   - 1段型と2段型を用意し、2段型は1段型の隣に優先配置[cite: 19.1]。
   - トラップモンスターに乗ると **2秒間操作不能（拘束）** され、解除後は **1秒間の無敵時間** を付与[cite: 19.1]。
   - 設定された描画距離（LOD）に応じて動的に描画/非描画を処理[cite: 19.1]。

3. **「挑発」廃止 ＆ 新機能「突進」追加**:
   - 挑発ボタンを廃止し、操作の邪魔にならない外枠円形状SVGクールダウンゲージ付き「突進」ボタンを新設[cite: 19.1]。
   - 発動時：1秒間速度 **20.0** で高速移動（スタミナ10消費、15秒クールダウン）[cite: 19.1]。
   - 突進追加効果：発動時に **半径5以内の追跡者を3秒間拘束（足止め）** ＆ **チェイス状態を強制解除**[cite: 19.1]。
