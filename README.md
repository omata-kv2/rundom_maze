# MAZE ESCAPE - 3D Prototype

HTML / JavaScript / Three.js を使った一人称ホラー迷路ゲームの初期プロトタイプです。

## 起動方法
- GitHub Pages に配置して公開する方法を推奨します。
- ローカルで試す場合は、プロジェクトフォルダで簡易HTTPサーバーを起動してください（ES Modulesを使うため、`file://` 直開きでは動作しない場合があります）。
- Three.js は jsDelivr CDN から読み込みます。初回起動時はインターネット接続が必要です。

## GitHubへの配置
ZIPを展開し、`index.html`、`style.css`、`game.js`、`assets` フォルダをリポジトリのルートに配置してください。
既存プロジェクトに同名ファイルがある場合は、内容を確認してから置き換えてください。これは新規プロトタイプ一式です。

## 操作
- PC：WASDで移動、Shiftで走る、マウスで視点操作
- iPad / タッチ端末：左スティックで移動、右側領域ドラッグで視点操作、「走る」ボタンで走る

## 現在の仮設定
- 迷路：21×21セルの完全ランダム迷路
- 1セル：4ワールド単位
- プレイヤー：歩行3.2、走行6.0
- スタミナ：最大20。走行中は毎秒1消費。歩行中・停止中は毎秒1回復
- 追跡者：3枚の画像からゲーム開始時に1枚選択。巡回中に視界内のプレイヤーを発見すると追跡
- ゴール：スポーンから直線距離32ワールド単位以上を目標に配置

## 調整場所
`game.js` 冒頭の `CONFIG` を変更してください。

## 注意・今後の改善候補
- これは動作確認用の初期版で、マップ寸法・敵AI・速度・視認条件は仮設定です。
- 迷路生成は完全ランダム方式の簡易版です。
- 追跡者の視認判定は視野角・距離・壁による遮蔽を使った簡易判定です。
- 音、演出、設定画面、難易度、複数階層、セーブ機能などは未実装です。
- スマートフォン・iPadでは端末やブラウザにより操作感が異なるため、実機テストが必要です。
