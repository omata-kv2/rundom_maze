# YAJU ESCAPE v23

## v23 アップデート

### 既存ステージ
- 通常ステージとボスステージの制限時間を各60秒に統一。
- HUDから「探索中」を削除し、階数／ステージ名と残り時間を表示。
- ロケットは段差の高さを参照して、段差内部に埋まらない高さへ配置。
- 追跡者は段差セル上に乗るよう高さを追従。

### ボスステージ
- 通常ステージ5階層をクリアすると、クリア画面に「ボスステージ」欄を表示。
- 「world enemy」「獣　王」の2種類を選択可能。
- 10×10セルの外壁ステージ。トラップモンスターなし、段差のみを配置。
- ロケットを3個生成。
- スタミナの代わりに最大20の体力を表示。体力は自然回復しない。
- 突進はスタミナ消費なし、5秒クールダウン。
- 走るボタンを非表示にし、通常移動速度を従来の走行速度へ変更。

### death caught / deadstage
- ボス戦で体力が0になると、元ステージの生成物を破棄してdeadstageへ移動。
- 床・壁・天井・ライトのない黒い空間に4体の追跡者を配置し、3秒かけて中央へ移動。
- イベント中は視点操作のみ有効。通常のダメージは無効、caught判定を有効化。
- caught後に `./assets/videos/inmuking.mp4` を再生し、28秒後に再スタートボタンを表示。
- 再スタート先は「1階からやり直す」「同じボスと戦う」の2種類。

### world enemy
- 追跡者の攻撃に2秒クールダウンを設定。今回の元ZIPにはworld enemy固有の攻撃力設定がなかったため、攻撃ダメージは仮に4として実装。

### 獣　王
- 既存追跡者画像を2倍サイズで使用し、HP100。
- 常時プレイヤーを追跡。通常移動速度5。
- 10秒ごとに2秒間、速度10のボス突進を発動。
- 通常攻撃4ダメージ／1.5秒クールダウン。
- ロケット命中15ダメージ、突進中の接触5ダメージ（1回の突進につき1回）。
- HP0で撃破。クリア文言は「君は（ボス名）を倒した！！」。

## 必要な既存アセット
このZIPには既存アセットを含めていません。元のGitHubリポジトリにある次のファイルはそのまま残してください。

- `assets/chasers/inmu_king.png`
- `assets/chasers/boom.png`
- `assets/items/rocket.png`
- `assets/videos/inmuking.mp4`
- 既存の音声・テクスチャ一式

獣王専用画像は今回提供されていないため、既存の `inmu_king.png` を2倍サイズで使用します。
