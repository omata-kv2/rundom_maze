# MAZE ESCAPE - Backrooms Edition

Three.jsを使った一人称ホラー迷路ゲームの改良版です。

## 起動
- `index.html`をGitHub PagesなどのHTTPサーバーで公開してください。
- ES ModulesとThree.js CDNを使うため、`file://`での直接起動は推奨しません。
- 初回起動時はインターネット接続が必要です。

## 操作
- PC：WASDで移動、Shiftで走る、マウスで視点操作
- iPad / タッチ端末：左下スティックで移動、画面右半分をドラッグして視点操作、右下の大きな「走る」ボタンで走る

## 改良点
- iPad/iOSの文字選択・長押し選択・タップ時の青いハイライトを抑制
- 右半分全体を透明な視点操作領域に変更
- 走るボタンを右下に移動し、大型化
- 壁と天井の高さを従来の約2倍に変更
- 迷路に広い部屋、ループ分岐、隠し通路を追加
- カーペットの細かな模様、黄色系の壁・床、霧、照明でBackrooms風の空間に変更
- ゴールをEXIT表示付きの非常口に変更し、接触で脱出
- 追跡者の初期位置をプレイヤーとゴールから離して選択
- 追跡者の追跡経路更新を間引き、負荷を抑制
- 捕まったときに画面を覆うジャンプスケアと揺れを追加

## ファイル
- `index.html`
- `style.css`
- `game.js`
- `assets/chasers/`：追跡者・ジャンプスケア画像

## 注意
- iPad実機でタッチ感度、描画負荷、画面サイズを確認してください。
- Three.jsはCDNから読み込むため、オフラインでは起動しません。
