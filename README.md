# YAJU ESCAPE v22 (仕様完全修正版)

## v22 の変更内容

1. **iPadでのスタート時誤再生不具合修正**:
   - `startGameFromSettings` 時に `stopCaptureVideoImmediately()` を実行し、`start.mp3` のみ流して動画再生を確実に遮断[cite: 19.1]。
2. **突進仕様の全面刷新**:
   - クールダウン: **5秒**[cite: 19.1]。
   - 効果時間: **2秒間**（速度20.0）[cite: 19.1]。
   - 音声効果: 発動時に `totugeki.mp3` を **4秒間** 再生[cite: 19.1]。
   - 突進状態の効果: 拘束効果を完全削除。突進中に接触した caught 判定は即座に **「追跡者の爆破・撃破判定」** に変化[cite: 19.1]。
3. **ロケットの階層引き継ぎ仕様**:
   - 前の階をゴールした際にロケットを所持（1発だけでも可）していれば、次の階層開始時に最大弾数（2発）で所持状態からスタート[cite: 19.1]。
4. **段差・トラップモンスターの調整**:
   - 段差の幅をセル一杯に拡大（壁にピッタリ接触可能）[cite: 19.1]。
   - トラップ効果を拘束から **3秒間の移動速度1/2化（歩き・走り・突進すべて半減）** に変更[cite: 19.1]。
   - 色設定：段差＝床/壁と同じ黄色（`#aaa080`）、トラップモンスター＝床/壁の黄色よりほんのり赤い黄色（`#bb9368`）[cite: 19.1]。
5. **追跡者の守備行動削除 ＆ 探知範囲調整**:
   - ゴール前ガード行動を完全に廃止し、全員ランダム巡回行動に変更[cite: 19.1]。
   - 追跡者の探知範囲を現在の2/3相当である **11** に調整[cite: 19.1]。
