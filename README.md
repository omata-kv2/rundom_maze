# MAZE ESCAPE - Backrooms Edition (v2)

## 概要
Three.jsを使用した、iPad対応の一人称視点ホラー迷路ゲームの第2次アップデート版です。

## 更新内容 (v2)
- **iPad対応の強化**: `pointerdown`イベントの採用と、ゲーム開始後のテキスト選択（青ハイライト）を無効化。
- **追跡者AIの改善**: スタート位置からの距離を保ったスポーン、視線判定による追跡/巡回の切り替え、巡回範囲を拡大（A*アルゴリズムを利用）。
- **レーダー機能**: 画面右上に3色（緑・黄・赤）で距離を示し、針で方向を指すレーダーを追加。
- **捕獲演出**: 動画（`inmuking.mp4`）の再生と、独立管理された27秒間のコンティニュー待機制限を追加。
- **再挑戦機能**: 初回生成時のマップデータを保持したまま、同じマップでリトライ可能に。
- **リソース統一**: 追跡者画像を `inmu_king.png` のみに統一。

## ファイル構成と配置方法
以下の構成になるようにファイルを配置してください。
（提供されているZIP内にはダミーファイルが含まれているため、本物のファイルで上書きしてください）

```
MAZE_ESCAPE_Backrooms/
├── index.html
├── style.css
├── game.js
├── README.md
└── assets/
    ├── chasers/
    │   └── inmu_king.png (本物の画像に差し替えてください)
    └── videos/
        └── inmuking.mp4  (本物の動画に差し替えてください)
```

## 起動方法
1. ローカルサーバー（VSCodeのLive Server拡張機能やPythonのhttp.serverなど）を使用して `index.html` を開いてください。
2. セキュリティ制約等により、必ずサーバー経由で起動してください（file://プロトコルでは動作しません）。
