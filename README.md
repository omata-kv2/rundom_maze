# YAJU ESCAPE v23.3

## v23.3 の新機能・仕様変更
1. **全ボスステージ共通のプレイヤー仕様変更**:
   - スタミナ制限を撤廃。
   - 移動時、走るボタンが消失し**常時走るスピード**で移動可能（消費不要）。
   - **突進が消費なし・5秒のクールダウン**で使用可能。
2. **「world enemy」追跡者の攻撃調整**:
   - 召喚された追跡者の攻撃に **2秒間のクールダウン** を追加。
3. **新ボス「獣 王」追加**:
   - 見た目が通常の追跡者の2倍（4.0x4.0セルサイズ）。
   - 常にプレイヤー位置を把握し、通常は**速さ5**で追跡。
   - スタートから**10秒ごとに2秒間、速さが2倍（速さ10）**になる突進能力を発動。
   - 当たり判定は大きさに応じた判定に拡張。caughtは無効で、**1.5秒のクールダウン付き通常攻撃（4ダメージ）**を行う。
   - HPは100。「ロケット命中：15ダメージ」「突進接触：5ダメージ（一突進につき1回のみ）」で撃破可能。
   - 撃破時は clear stage イベントへ遷移し、「君は獣 王を倒した！！」と表示。
