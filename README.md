# YAJU ESCAPE v18 (捕獲演出・階層リトライ・音声制御版)

## v18 での修正・追加内容
1. **CAUGHT（捕獲）時の27秒間演出・操作不能化**:
   - 捕まった瞬間、全画面ブロックオーバーレイと `inmuking.mp4` が再生され、27秒間は一切の操作およびタップ・クリックが不能になります。27秒経過後にゲームオーバーダイアログが表示されます。
2. **「同じ階をやり直す」ボタンの追加**:
   - ゲームオーバー時に、1階からやり直すだけでなく、現在の階層をもう一度やり直せるボタンを追加しました。
3. **リスタート音声（restart.mp3）の正確な制御**:
   - 「同じ階をやり直す」「1階からやり直す」どちらの再挑戦ボタンでも、**ボタンを押してから1秒間待機したあと、`restart.mp3` を2秒間再生**するように実装しました。
