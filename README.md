# YAJU ESCAPE v23 (アップデート完了版)

## 修正・実装内容
1. **既存システムの修正**:
   - ロケット生成位置を段差の上に最適化（埋もれ防止）。
   - 追跡者の段差当たり判定を追加し、段差を貫通して移動しないように修正。
   - 戦闘時間を60秒に統一。「探索中」表記を削除。
2. **ボスステージの解放・選択**:
   - クリア後にボスステージ選択欄（world enemy / 獣王）が出現。
3. **ボスステージ共通仕様**:
   - 10×10セル、トラップなし段差、ロケット3つ、体力バー（20）システム、突進CD5秒。
4. **death caught・deadstageイベント**:
   - 体力が0になると専用deadstageへ強制移動。追跡者4体が接近しcaughtされるとinmuking.mp4が28秒再生。
5. **world enemyステージ**:
   - 追跡者の攻撃に2秒のクールダウンを追加。
6. **新ボス「獣　王」**:
   - 2倍の大きさ、HP100、10秒ごとに2秒間の突進、ロケット命中で15ダメ、突進中接触で5ダメ。
7. **スタートの堅牢化**:
   - ロード画面スタックを防ぐエラーハンドリング付き起動関数を実装。
